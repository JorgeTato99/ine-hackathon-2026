## Registro de observación

| Tarea/orden | Resultado observable | Ejecución | Comprensión | Frase o duda sin identificación | Ayuda y momento | Incidencia/tiempo aproximado |
| ----------- | -------------------- | --------- | ----------- | ------------------------------- | --------------- | ---------------------------- |
|             |                      |           |             |                                 |                 |                              |

Ejecución: independiente / con ayuda / fallo / abandono; no realizada e
incidencia técnica se anotan aparte. Comprensión: adecuada / parcial / errónea /
sin evidencia. Ayuda: A0 ninguna, A1 repetición, A2 reformulación, A3 zona,
A4 acción. A0–A1 permiten independencia; A2–A4 cuentan como ayuda. Distinguir ayuda del moderador y ayudas usadas en la interfaz.
Las ayudas usadas en la interfaz no restan independencia. No rellenar una
comprensión que no se observó. En T8 separar guardar, recuperar y trasladar.
